# ドパドリル

農業の4択クイズに1問答えるたびに、演出と音楽がどんどん盛り上がっていくドリルです。中高生・農業高校向けの基礎知識を扱います。ブラウザだけで動きます。

※ 算数版「ドパドリル」（https://github.com/grmchn/dopa-drill）の非公式フォーク（改造版）です。

マスコットの「ドパキチ」が選んだ番号を運び、正解すると祝ってくれます。問題を進めるほど画面と音が増えていき、最後はお祭りのような状態になります。まちがえても勢いは落ちず、ゲームオーバーもありません。

## 特徴

- 農業クイズ24スキル・約170問。「作物・野菜」「土・肥料」「病害虫・環境」「畜産・食品」の4分野×レベル1〜6
- 選択肢は毎回シャッフル。まちがえた選択肢は選べなくなります
- 問題は `app/js/quizbank.js` に `[問題文, 正解, [まちがい3つ]]` の形で追加できます
- 「じぶんレベル」モード：実力チェックの結果から始め、習熟に合わせて次のスキルを解放します
- レベル別モード、練習、復習、スキルツリー画面
- 全問正解で100点。初回正解率が80%以上なら、制限時間付きのエクストラで100点を超える得点を狙えます
- 音楽と効果音はすべてWeb Audio APIで合成しています（音声ファイルは使っていません）
- スマートフォンの縦画面とPCに対応。PCでは数字キーの1〜4で答えられます
- 設定で動きの強さを調整できます。ミュートもあります
- 記録はすべて端末内（localStorage）に保存し、外部には送信しません
- PWA対応：ホーム画面に追加してアプリのように使え、一度開けばオフラインでも遊べます

## 遊び方（ローカル）

ビルドは不要です。`app/` を静的に配信するだけで動きます。

```bash
python3 -m http.server 8000 -d app
```

ブラウザで `http://localhost:8000/` を開いてください。ES Modulesを使っているため、`file://` で直接開くと動きません。

## テスト

Node.js 20以上で実行します。

```bash
node --test tests/*.test.mjs
```

## 構成

| パス | 内容 |

| `docs/SPEC.md` | 仕様書（算数版のもの。演出・得点の仕組みは共通） |
| `docs/curriculum.md` | 算数版のカリキュラム（参考） |

| `tests/` | 単体テスト |
| `tools/build_fonts.sh` | フォントのサブセット再生成（画面の文言を追加したときに実行） |
